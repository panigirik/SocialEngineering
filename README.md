# SocialEngineering
Social engineering tutorials


This project is a collection of educational C# programs demonstrating a variety of security techniques and best practices for software protection. The toolkit includes working implementations of multiple security mechanisms, designed to provide hands-on experience with different types of attacks and defenses in software systems.

Features

Code Obfuscation: Detects and renames methods, shuffles code blocks, and produces functionally equivalent but harder-to-read C# code to make reverse engineering more difficult.

SQL Injection Protection: Demonstrates safe handling of database queries using parameterized statements to prevent injection attacks.

Encryption and Decryption: Provides basic examples of cryptographic operations for secure storage and transmission of sensitive data.

Buffer Overflow Protection: Shows safe memory handling techniques to prevent buffer overflow vulnerabilities.

Kerberos Authentication Simulation: Implements a simplified version of the Kerberos protocol for secure user authentication and ticket-based access control.

DOS Attack Awareness: Illustrates detection and mitigation strategies for basic denial-of-service scenarios.

Social Engineering Awareness: Includes examples and explanations of how human factors can be exploited, and demonstrates defensive programming techniques to reduce risk.

Purpose

The toolkit is fully functional and intended for educational purposes. It allows users to experiment with multiple security concepts in practice, understand attack vectors, and see how defensive programming and protocol design can protect software systems. Each module is designed to show both the problem and the mitigation clearly.

Usage

Clone the repository.

Explore individual modules for different security scenarios.

Run the programs to see examples of attacks and how protection mechanisms operate in practice.

Modify or extend modules to experiment with additional defensive techniques.
